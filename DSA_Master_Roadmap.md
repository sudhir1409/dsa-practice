# Problem Solving Framework

## Step 1: Understand Input

Identify whether the problem uses:

- Array
- String
- Linked List
- Tree
- Graph

## Step 2: Check Constraints

- Small input → O(n²) may work
- Large input → Aim for O(n log n) or O(n)

## Step 3: Identify Pattern

| Clue | Pattern |
|--------|---------|
| Pair Sum | Hashing / Two Pointers |
| Longest Subarray | Sliding Window |
| Frequency | HashMap |
| Sorted Array | Binary Search |
| Shortest Path | BFS / Dijkstra |
| Choices | Backtracking |
| Overlapping Problems | Dynamic Programming |

## Step 4: Solve In Stages

1. Brute Force
2. Better Solution
3. Optimal Solution
